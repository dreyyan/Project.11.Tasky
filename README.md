**Tasky** is a comprehensive, intuitive, and organized to-do management system that allows you to manage your tasks instantly.

The purpose of Tasky is to help users create, update, and organize their to-do list using natural language commands.
It leverages intelligent text parsing to understand user instructions, allowing you to add, remove, update, and view tasks without complex menus. The system ensures robust input handling and validation so you can interact with it smoothly and without errors.

The primary use case for this program is to enable users—students, professionals, or anyone with a busy schedule—to efficiently manage their daily tasks, deadlines, and reminders. Tasky adapts to flexible command formats, making it both beginner-friendly and efficient for power users.

**FEATURES**  
✅ Add, remove, update, and view tasks using natural language commands  
✅ Intelligent input parsing for flexible phrasing  
✅ Minimalistic yet functional CLI interface
